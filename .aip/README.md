# .aip

本目录由 AIP 初始化生成，存放该仓库 AIP 机制的全部产出（隐藏工具目录，类比 .git）。

条目（一条一个文件，文件名 `时间戳_类型_状态_简述.md`，用 aip 技能的 `aip_item.py` 新建和改状态）：

- `knowledge/`：知识库（验证过的根因/坑/领域事实，先查后挖）
- `decisions/`：架构/方向级决策
- `inbox/`：旁路问题收件箱（干 A 时撞见的无关问题，捕获别追）
- `tracks/`：在建线，做完就删（随这条线最后一个 MR 提交）

整篇文档：

- `reference.md`：本工程权威参照（领域概念/术语、核心铁律、可复用实现）
- `conventions.md`：项目铁律和规约（怎么干的常驻规则）
- `config.yaml`：验证命令、上次整份 review 的日期、按哪一版 AIP 模板整理过（`aip_version`）

看板不存文件：会话开始钩子直接打印在建线和待处理旁路问题；没有钩子就看 `tracks/` 和 `inbox/` 下带 `_open_` 的文件名。
